# Security Policy

## Reporting a vulnerability

Please **don't open a public GitHub issue** for security problems.

Email **support@anydeploy.app** with the subject line `SECURITY`. Include:

- the anyDeploy version (Settings → About, or the installer filename)
- your OS and the target type involved
- steps to reproduce, and what an attacker could do with it

We'll confirm we received your report and keep you updated while we work on a fix. Please give us a reasonable amount of time to release a fix before you disclose the issue publicly.

## Supported versions

Only the [latest release](https://github.com/JPEG111/anydeploy-releases/releases/latest) gets security fixes. anyDeploy updates itself, so keep auto-update on.

## Before you share logs

Remove your **license key**, API tokens (for example Cloudflare) and any environment variable values before you paste logs anywhere, including in issues.
